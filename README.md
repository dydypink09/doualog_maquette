# DOUALOG Control Tower — Maquettes V1

Maquettes cliquables de la future plateforme DOUALOG : écrans de l'équipe, pages du client et du transporteur, emails.
Toutes les données sont fictives.

## Ouvrir les maquettes

1. Double-cliquez sur **`output/index.html`** : le sommaire s'ouvre dans votre navigateur (Chrome ou Edge conseillés).
2. Cliquez sur **« Lancer la démo »** pour suivre pas à pas le dossier DLG-2026-0412, de l'email du client jusqu'à la facture.
   Ou ouvrez n'importe quel écran depuis le sommaire.

Une **connexion internet** est nécessaire pour afficher la police Inter. Sans connexion, les écrans restent utilisables
avec une police de remplacement.

Les actions faites pendant une démonstration (facture émise, document déposé…) sont gardées tant que l'onglet est ouvert.
**Fermez l'onglet** pour tout remettre à zéro.

## Pour l'équipe de développement

- `output/design-system.html` : couleurs, textes et composants utilisés par tous les écrans.
- `QUESTIONS-ONCLE.md` : les questions encore ouvertes pour DOUALOG.
- `CLAUDE.md` : règles de construction des maquettes.
